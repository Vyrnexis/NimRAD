# NimRAD audit (2026-11-20)

Scope: all of `src/` (7.7k lines). Read-only audit; nothing changed yet.
IDs are for tracking the fixes. ✔ = confirmed by reading the code a second time.

## P1 — data loss, crashes, stuck states

| ID | Where | Problem | Fix |
|---|---|---|---|
| A1 ✔ | `unitimports.importsFor`, `syncFromNfm`; `uniteditor.syncLoadedImports` | An `.nfm` that does not parse (hand edit, merge markers) gives an empty import list, so opening the unit strips every nimvcl import from the code and marks it modified; Save writes it. `readFile` there is unguarded. | `importsFor` reports parse failure; `syncFromNfm` returns `src` unchanged; skip when `loadError` is set; guard the read. |
| A2 ✔ | `saveActive`, `saveAll`, `closeEditor`, `onCloseQuery` (mainform), `closeProject`, `setRunParameters`, `applyOptions` | `UnitEditor.save` / `Project.save` can raise (read-only, disk full); nobody catches it, the exception escapes the action or the close handler. | One `trySave(ed): bool` / `trySaveProject` that reports through `ide.fail`; a failed save counts as Cancel when closing. |
| A3 ✔ | `mainform` `onCloseQuery` | Saves editors in tab order with `e.save()`, bypassing `saveAll`'s descendants-before-ancestors order and `saveEditor`'s rebase → an inherited form's diff can be computed against the new ancestor. | Prompt per editor, then save the chosen ones through the `saveAll` ordering. |
| A4 | `uniteditor.save` + nimvcl `CodeEdit.saveToFile` | `saveToFile(tmp)` marks the model saved before the rename; if `moveFile` fails the tab shows clean and closing does not prompt. | Re-mark modified on failure (and nimvcl: a save-copy that does not mark saved). |
| A5 ✔ | `projectcommands.removeFromProject` | Closes the unit's editor, then `removeUnit` raises (ancestor of another form, main-file write) with no `try`. | Check "is an ancestor" before closing; wrap in `try` → `ide.fail`. |
| A6 ✔ | `openProject`, `newApplication`, `closeProject` vs `buildcontroller` | Not disabled while compiling/running. Project B gets A's messages, `autoAddImports` edits B's files from A's errors, run-after-build starts B's exe. | Refuse (or Reset and wait) while `ide.busy`; disable the actions; `compileDone` checks the project is still the one it built. |
| A7 | `builder.streamProcess` | Only `OSError` from start is caught. Any other exception in the worker skips `DoneMsg`: IDE stays busy forever, child not waited. | `try/finally` in the worker: always `waitChild`, always send `DoneMsg`. |
| A8 | `uniteditor.deleteSelection` | The inherited/descendant check covers the selected controls only, not their children. Deleting a Panel breaks descendants that use its children. | Run the check over each selected subtree. |

## P2 — correctness

| ID | Where | Problem | Fix |
|---|---|---|---|
| B1 ✔ | `codegen` proc header parse (~l.130) | First `:` after `(` is taken as the first parameter's type, so `proc makeForm(): Form1` counts as a handler (inspector dropdown, stub anchor, empty-handler scan). | Only a colon before the matching `)`; require a parameter. |
| B2 | `messages` parser | A location-less `Error: execution of an external compiler failed` closes the message; gcc/ld lines after it are dropped from Messages. | Keep a location-less Error open for continuation lines. |
| B3 ✔ | `builder.compileArgs` | No `--errorMax`, so Messages shows one error only (Delphi lists all). | Add `--errorMax:100`. |
| B4 | `buildcheck` | False "up to date": output dir = project dir excludes every project file; `--out`/`-o` in flags makes `exePath` wrong; deps stamped with a stat taken after the build (a `cp -p` during the build slips through). | Always build when the output dir is not a strict subfolder or flags carry `--out`; stat deps before compiling. |
| B5 | `proctree`, `builder` | Pipe write end not close-on-exec atomically (another spawn inherits it → read never ends); Reset can `kill(-pid)` / `TerminateJobObject` after the child was reaped (pid or handle reuse). | `pipe2(O_CLOEXEC)` (Linux), serialise spawns elsewhere; clear `pid`/`job` before `waitChild` under a lock. |
| B6 | `newApplicationProject`, `applyOptions` (import mode), `project.removeFont` | Multi-file operations without rollback: a failure leaves `unit1.*` behind (retry refused) and the IDE with no project; half the units rewritten; a font file deleted before the project is saved. | Reuse `Undo`/`writeTracked` from `renameUnit`; delete the font file last; close the old project only after the new one exists. |
| B7 | `project.toJson` | Unknown keys inside unit and font records are dropped on save (top-level ones are kept, as documented). | Keep an `extra: JsonNode` per record. |
| B8 | `project.addFontFile`, `fontsBlockLines` | Two files with the same family + style emit the same `const` → the user's program does not compile. | Refuse the duplicate in `addFontFile`. |
| B9 | `project.unitAndForm` | Unit `button` → form type `Button`, shadowing nimvcl's; Nim keywords accepted as unit names. | Refuse keywords and names of registered nimvcl classes. |
| B10 | `projectcommands.addToProject` | No check that the file exists / is `.nim`; relative path resolved two different ways; `.nfm` that does not parse gives a form unit with empty `formType`. | Validate first; refuse an empty form type. |
| B11 | `projectcommands.openProject` | Any load error drops the project from Recent (corrupt, newer format, permission). | Only drop it when the file is missing. |
| B12 ✔ | `ideeditors.closeEditor` | Closing a background tab moves the active tab. | Only reassign when the closed editor was active. |
| B13 | `quickfixes.applyFix`, `autoAddImports`, `symbolindex` | Fixes replay line/column from the last build without checking the file; auto-import adds imports for noisy index names (`caption`, `add`, `else`…); a fix in a non-project file says "already imported". | Store the line text and verify; restrict auto-add to types/consts; outcome enum for the messages. |
| B14 | `codegen.findProc`, `hasProc`, `renameComponentRefs` | Exact name compare; Nim is style-insensitive → duplicate stub for `button1click`. | Compare with `cmpIgnoreStyle`. |
| B15 | `mainfile.callsCtor`, `crlf` | Commented `# let x = newForm1()` is taken as a create line; CRLF detected from line 0 only. | Strip comments; detect from any line. |
| B16 | `uniteditor.save` | No check that the `.nim`/`.nfm` changed on disk since loading; external edits are overwritten silently. | Keep a stamp at load; ask before overwriting. |
| B17 | `unitimports` | An import leaves when the last object of a class leaves the form, even if the code still uses the class. | Keep the import while the code names the class. |
| B18 ✔ | `ideform.AppVersion` | Hard-coded `0.0.1`; About shows it. | Take the version from `nimrad.nimble` at compile time. |
| B19 | `ideeditors.refreshActions` | Revert to Inherited enabled for rows that are not overridden and while the code view shows. | Use `canRevertProperty`/`canRevertComponent` and `routeToDesigner`. |

Minor (batch together): caret lands on the hint comment of an inherited stub (`codegen` ~l.224); a file with mixed line endings is rewritten as all-CRLF; import fallback inserts inside a multi-line `import a,\n b`; `reloadFromDisk` computes `selName` and never restores it; `teardownDesign` may leave the hidden model form alive (verify); `nimvclpath` can return a relative path; `fileio` replaces a symlink with a file and drops permissions; `loadProject` does not reject duplicate unit names; `&` in a recent-menu caption becomes a mnemonic; no positional `.nimproj` argument (file association), unknown flags ignored; `saveSettings`/`loadLayout` failures silent; a partial output line waits for a newline; Reset reports "cancelled" for a job that had just finished; SIGKILL without SIGTERM first; toolbar uses `aExit` as a separator sentinel.

## Notes for the nimvcl audit

- `CodeEdit.saveToFile` marks saved and sets `fileName` to the tmp path: needs a `saveCopyTo` that does neither (A4).
- `Form` has no `onCreate` event (Delphi's default form event).
- `Action` has one shortcut only (NimRAD duplicates `aNextMessage` for a second key).
- `DockSite`: no panel shown/hidden event (NimRAD polls); `loadLayout` gives no reason for failure.
- `PageControl`: no closable tabs (NimRAD pads `sheetTabText` and copies private constants); check `EditorPages.doMouseDown` bypassing `PageControl`'s override.
- `TreeView`: `items.clear` loses expansion/scroll, no keyed update, single select only; `onKeyDown` needs `key = Key(0)` to swallow (no `handled`).
- `ListView`/`Memo`: no begin/endUpdate or bulk append, no virtual mode; `tag` is int only.
- `MessageKind` and `MarkerKind` both define `mkError`.
- `runOnUi` moves data via `allocShared0`: fine under ORC, unsafe under refc — assert the memory manager.
- `runQueued` re-raises job exceptions by default, which can end the app loop; no global unhandled-exception hook for UI handlers.
- No modal helper that frees the window on exceptions; dialogs are laid out by absolute coordinates.
- `FormDesigner.onModified` used for everything — check whether it fires per drag step; a "committed" event would help.
- `NfmError` vs `CatchableError` inconsistent between `parseNfm` and `loadNfm`; no shared helper to resolve and read an ancestor `.nfm`.
- Font registry: check whether re-registering a family replaces or stacks; no per-face removal.
- Menu captions: is there an `&&` escape for a literal `&`?
